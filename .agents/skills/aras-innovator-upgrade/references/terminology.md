# 術語表

中文說明優先；Aras 產品名稱、物件名稱及業界常用縮寫保留英文，以利對照原廠文件和系統畫面。

| 術語 | 中文說明 | 使用方式 |
|---|---|---|
| Aras Innovator | 本專案升級的 PLM 平台 | 保留產品英文名稱 |
| ItemType | Aras 中定義資料物件類型的中繼資料 | 保留 Aras 介面名稱 |
| Relationship | Aras 物件間的關聯定義或關聯資料 | 保留 Aras 介面名稱 |
| Form / View | Aras 表單／檢視 | 首次可寫為「Form（表單）」 |
| Workflow | 工作流程 | 涉及 Aras 物件名稱時保留英文 |
| Lifecycle | 生命週期 | 涉及 Aras 物件名稱時保留英文 |
| Permission / Identity | 權限／身分 | 涉及 Aras 物件名稱時保留英文 |
| Method | Aras 中執行邏輯的程式方法 | 保留 Aras 介面名稱 |
| AML | Aras Markup Language | 保留縮寫 |
| Vault | Aras 管理檔案內容的儲存服務 | 保留產品術語 |
| Conversion Server | Aras 檔案轉換服務 | 保留產品術語 |
| Package | 用於匯出、匯入或部署 Aras 設定的套件 | 保留產品術語 |
| Service Pack / Hotfix | 服務套件／緊急修正 | 版本名稱依原廠寫法 |
| Runbook | 可逐步執行並含證據、停止與回復條件的作業手冊 | 文件中可寫為「升級 Runbook」 |
| Rollback | 將系統回復至升級前可用狀態 | 文件中可寫為「回復（Rollback）」 |
| Go/No-Go | 繼續上線或停止／回復的正式決策 | 保留常用術語 |
| RTO | Recovery Time Objective，復原時間目標 | 首次列出中英文及縮寫 |
| RPO | Recovery Point Objective，復原點目標 | 首次列出中英文及縮寫 |
| Checksum | 用於確認檔案完整性的校驗值 | 保留常用術語 |
| Idempotency | 同一步驟重複執行不造成額外非預期變更的特性 | 寫為「重複執行安全性（Idempotency）」 |

## 紀錄狀態

| 狀態 | 定義 |
|---|---|
| 已驗證 | 有可追溯證據支持 |
| 相關人員提供 | 由人員說明，但尚未取得客觀證據 |
| 假設 | 暫時採用，且已有驗證行動 |
| 未知 | 尚無足夠資訊 |
| 不適用 | 已確認不在本次範圍 |
| 待確認 | 需要指定人員於期限前回答或決策 |
| 待處理 | 已確認需要執行，但尚未完成 |
| 已完成 | 已符合預期結果並取得指定證據 |
| 已阻礙 | 因缺少條件、決策或資源而無法繼續 |
