# 升級關卡檢查表

使用本檢查表確認各階段是否就緒。先確認適用的 Aras 版本和環境，再於該次升級計畫中補充精確指令和證據要求。

## 盤點完成條件

- [ ] 來源及目標版本已驗證。
- [ ] 有證據支持所選升級路徑。
- [ ] 環境及元件已完成盤點。
- [ ] 客製化和整合項目均有負責人。
- [ ] 已確認資料庫與 Vault 的容量和健康狀態。
- [ ] 已確認維護、復原和資安限制。
- [ ] 已指定技術及業務驗收負責人。

## 演練進入條件

- [ ] 已連結精確版本的原廠文件。
- [ ] 前置條件及相容性檢查通過。
- [ ] 安裝媒體和 Checksum 已備妥。
- [ ] 備份及還原程序已測試，或風險已由權責人接受。
- [ ] Runbook 已依序排列，並包含停止條件和回復點。
- [ ] 測試資料和驗證 Script 已備妥。
- [ ] 演練環境已隔離且具有代表性。

## 正式環境進入條件

- [ ] 演練使用目前的 Runbook 版本。
- [ ] 演練發現的缺陷和偏差已解決或獲接受。
- [ ] 實際作業時間符合核准的維護時段。
- [ ] 正式環境備份為最新狀態，還原資源已就緒。
- [ ] 變更核准及 Go/No-Go 決策人已有紀錄。
- [ ] 操作人員、核准人員和升級通報窗口均可配合。
- [ ] 監控和溝通機制已就緒。
- [ ] Rollback 最晚決策時間明確。

## 升級驗收條件

- [ ] 技術健康檢查通過。
- [ ] 所有相關客製化和整合項目均已驗證。
- [ ] 關鍵業務情境測試通過。
- [ ] 資料及檔案完整性檢查通過。
- [ ] 例外及後續事項均有負責人。
- [ ] 技術及業務核准已有紀錄。
- [ ] 最終盤點、執行紀錄和交接文件均已完成。
