# 08 規則管理與版本化

Status: resolved

## 目標

建立 Rule 1／Rule 2 共用規則與版本例外的草稿、驗證、人工發布、不可變版本、Checksum、解析及衝突阻擋核心，並同步建立 `aras-manage-upgrade-rules` 功能 Skill。

## 驗收結果

- 預設 Rule 1 與 Rule 2 規則草稿可驗證。
- 重複順序、不支援步驟及無效參數會被拒絕。
- AI 與自動化不能建立、修改或發布規則。
- 發布必須有具名人工操作者與核准證據，且版本只追加不覆寫。
- 共用規則可被符合版號的例外依 `StepId` 覆蓋。
- 多個例外對同一步驟定義不同內容時會阻擋。
- 功能 Skill 引用正式受測核心，不複製規則邏輯，也不執行 Rule 1／Rule 2。
