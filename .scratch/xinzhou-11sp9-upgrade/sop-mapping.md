# SOP 對照

實際 SOP：`K:\03.升級工具及手順\11sp9TO12sp9\11sp9升级12sp9工作手顺.xlsx`

| SOP 工作表 | 內容摘要 | 對應案件關卡 |
|---|---|---|
| `11sp9-11sp12` | 11SP9 至 11SP12 前置調整、DB／Package 準備與升級步驟 | 來源環境盤點、客戶 Package 基準、第一階段升級準備 |
| `11sp12-11sp15` | 11SP12 至 11SP15 Package 匯入與備份 | 後續跳點 Package 與人工執行，不可套用到第一跳 |
| `11sp15-120` | 11SP15 至 12.0 AML／設定調整 | 後續跳點的 AML／設定工作，須另建跳點嘗試 |
| `120-12sp9` | 12.0 至 12SP9 Package、Server Event、中文化與最終備份 | 12.0→12SP9 跳點，須等待前一跳完成與備份 |

重要限制：

- SOP 中的 SQL、AML、BAT、帳號資訊及實際路徑不是本範例的可執行授權。
- 正式執行前必須固定來源檔案版本與 Checksum，並由操作人員確認環境與備份。
- Prompt 只能協調與記錄；不會自動連線 DB、執行 SQL、啟動 `consoleUpgrade` 或操作 Aras Export。
- 這份範例先處理 11SP9→12SP9；若要繼續到 12SP18、R38 或其他版本，必須由操作人員提供並驗證完整連續路徑。
