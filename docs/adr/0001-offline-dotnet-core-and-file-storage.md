# 0001：離線 .NET 核心與案件目錄檔案儲存

狀態：已採用  
日期：2026-08-03

## 背景

第一版是單機 Windows 桌面工具，核心流程不得依賴 AI 或中央服務，案件資料與不可覆寫歷程必須保存在客戶升級目錄。第一階段尚不需要桌面畫面，但後續需要能由 Windows UI 呼叫相同核心。

## 決策

- 使用 .NET 8 類別庫建立與 UI 無關的領域及應用核心；後續桌面層只依賴公開介面。
- 案件根層使用 `aras-upgrade-case.json` 作為案件清單。
- 工具專用資料置於 `.orchestrator/`；不可覆寫歷程使用只追加的 JSON Lines 檔案。
- 外部或危險動作一律透過 `IExternalActionExecutor`；核心預設使用阻擋實作，測試使用替身。
- 執行狀態由案件清單與歷程重建，不把可變的「目前狀態」當成唯一事實來源。

## 影響

- 核心可離線測試，也不會因 UI 或 AI 不可用而失效。
- JSON 檔案適合第一版單人案件；未來多人共享模式需要另立 ADR 評估交易與併發儲存。
- Package／AML 實作仍必須遵守 AML 共用標準，不會因本 ADR 而將 AML 視為一般 XML。
