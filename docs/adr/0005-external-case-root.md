# 0005：允許受控的專案外案件根目錄

狀態：已採用
日期：2026-08-28

## 背景

案件資料通常需要與專案原始碼分離保存。芯洲案件預計放在 `K:\70.ArasUpgradeCases\芯洲`，但案件建立 Prompt 將專案編輯限制誤套用到案件資料，造成合法的外部案件根目錄被阻擋。

## 決策

1. 允許案件根目錄位於專案目錄外。`DIRECTORY_SCAFFOLD_ONLY` 可使用使用者在本次要求中明確指定的固定案件根目錄，不要求另一個尚不存在的 UI／CLI 或 command/action。
2. 外部寫入仍採兩層限制：使用者明確指定固定完整根目錄，以及執行環境對相同根目錄授予寫入權限。環境可提供持久安全白名單，但它不是目錄骨架建立的唯一授權入口。
3. `VALIDATE_ONLY` 僅驗證參數與安全固定路徑，不進行寫入。
4. `DIRECTORY_SCAFFOLD_ONLY` 必須通過本次固定根目錄授權、權限、既有案件資料與鎖檢查，才可在外部案件根目錄建立骨架；它只可建立目錄與非正式範本。
5. 專案原始碼與文件仍只能在專案目錄修改；案件資料、輸入與產出才可保存於外部案件根目錄。

## 影響

- Prompt 與操作文件必須明確區分專案編輯範圍及外部案件資料範圍。
- `K:\70.ArasUpgradeCases` 可作為芯洲範例的外部案件根目錄；實際執行時仍須取得執行環境對此固定根目錄的寫入權限。
- 環境尚未提供持久白名單登錄入口時，仍可在使用者明確授權後，請求此固定根目錄的單次寫入權限；不能以手工建立正式案件清單或繞過安全檢查。
